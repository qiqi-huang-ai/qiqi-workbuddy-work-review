# 案例制作记录

## 范围取舍

这个版本复用已验证的复盘工作台交互，只解决一个完整问题：查看 WorkBuddy 对话，选择与本次工作有关的记录，再生成可追溯的工作复盘。

保留：WorkBuddy 本地记录、任意时间段/全文关键词筛选、对话勾选、证据边界、用户修正、真实与演示数据隔离。

界面最终没有把“搜索对话”和“生成复盘”拆成两个页面，而是形成一条连续流程：筛选范围 → 查看命中原因 → 决定全部使用或手动勾选 → 确认最终证据 → 生成复盘。

不做：Codex 与其他来源混采、任务与目标管理、后台自动运行、月报和年报。

## 开源规则调整

早期原型曾读取外部复盘 Skill。为了让项目能够使用 MIT 协议独立开源，正式版本改为项目内原创的 `rules/review-rules.md`，不复制外部 Skill 的文案、模板或署名。旧版真实复盘只留在本机被 Git 忽略的 `data/` 中。

## 已验证

- 本地服务可在 `127.0.0.1:4319` 启动；
- WorkBuddy 会话数据库与 JSONL 记录可只读访问；
- 任意时间段复盘可由按钮手动触发；
- WorkBuddy 生成时禁用工具和会话持久化；
- AI 版本和用户修正分开保存；
- 真实数据文件不会被 Git 收录。

## 对外展示

发布文章、视频或 GitHub 截图时，只使用 `data/demo/` 中的脱敏资料。不得展示真实对话正文、客户名称、用户名、凭据或私人绝对路径。

待补素材：桌面端总览、对话选择、复盘详情、窄屏四张脱敏截图。
