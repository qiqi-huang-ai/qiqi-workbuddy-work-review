# Contributing

Thanks for helping improve WorkBuddy Review Workbench.

## Local development

1. Install Node.js 22 or later and WorkBuddy.
2. Run `npm start`.
3. Open `http://127.0.0.1:4319`.
4. Run `npm test` before submitting a change.

## Pull requests

- Keep changes focused on WorkBuddy conversation review.
- Do not commit real conversation exports, generated reviews, credentials, or absolute private paths.
- Add or update tests for behavior changes.
- Document user-visible changes in `ROADMAP.md`.

## Privacy

Use only `data/demo/` fixtures in screenshots, issues, and pull requests. Assume all files under the user's WorkBuddy data directory are private.
